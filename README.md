## 🌍 What is this?

New Delhi is asleep. Tilburg is having lunch. Or maybe it's the other way around — who can keep track?

This app can. It's a **live, side-by-side clock** for **New Delhi (IST)** and **Tilburg (CET/CEST)** that quietly does the timezone math nobody wants to do in their head, so you can stop opening five browser tabs just to ask *"wait, is it too early to call?"*

> IST never observes daylight saving. The Netherlands does. That means the gap between the two clocks **breathes** throughout the year — 3.5 hours in winter, 4.5 in summer. This site tracks that shift automatically.

## 🧭 Why bother?

Because "let's hop on a call" between India and the Netherlands always turns into a small diplomatic negotiation. IST sits fixed at **UTC+5:30** all year; the Netherlands slides between **UTC+1 (CET)** and **UTC+2 (CEST)**. This site puts both realities on screen at once, so scheduling a call takes one glance instead of a calculator.

---

## 🛠 Tech stack

A deliberately lightweight, dependency-free static site — just **HTML, CSS, and JavaScript**, using the browser's own `Intl` timezone APIs to do the heavy lifting. No backend, no build step, no framework to fight with.

Deployed straight from this repo via **GitHub Pages**:

```
🌐  https://samanway-koley.github.io/india-netherlands-time/
```
